# Лабораторная работа 7. Функции и автоматические проверки

## Как запустить
1. Демонстрация: `python main.py`
2. Проверки: `python test_functions.py`

---

## Структура файлов
- `functions.py` — все функции (`sum_digits`, `average`, `normalize_text`, `select_numbers`, `is_palindrome`).
- `main.py` — взаимодействие с пользователем.
- `test_functions.py` — автотесты через `assert`.

---

## Проверки

### `sum_digits`
| Вход | Ожидаемый | Факт |
|---|---|---|
| 0 | 0 | 0 |
| 507 | 12 | 12 |
| -507 | 12 | 12 |

### `average`
| Вход | Ожидаемый | Факт |
|---|---|---|
| `[]` | `None` | `None` |
| `[2, 4, 6]` | 4.0 | 4.0 |

### `normalize_text`
| Вход | Ожидаемый | Факт |
|---|---|---|
| `"  ПРИВЕТ   Мир  "` | `"привет мир"` | Совпадает |
| `"   "` | `""` | Совпадает |

### `select_numbers` (Вариант 1 — больше порога)
| Вход (список, порог) | Ожидаемый | Факт |
|---|---|---|
| `[-5, 0, 2, 5], 2` | `[5]` | `[5]` |
| `[], 2` | `[]` | `[]` |
| `[3, 3, 4], 2` | `[3, 3, 4]` | Совпадает (повторы сохранены) |
| `[2, 2, 2], 2` | `[]` | Совпадает (граница не включается) |
| `[-1, 0, 1], 0` | `[1]` | `[1]` |

### Дополнительные проверки
- Исходный список после `select_numbers` не изменяется.
- `is_palindrome("   ")` возвращает `False` (пустой нормализованный текст).

---

## Демонстрация обнаружения ошибки
Если в `select_numbers` заменить условие `num > threshold` на `num >= threshold`,
то проверка `assert select_numbers([2, 2, 2], 2) == []` упадёт с `AssertionError` —
тест обнаруживает граничную ошибку.
